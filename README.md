# Service and Complaint Management System
full-stack web application designed to log, track, and resolve user service requests and complaints efficiently with role-based access.

## Tech stack 
-- **Frontend:** React.js, Tailwind CSS
-- **Backend:** Java, Spring Boot, REST APIs
-- **Database:** MySQL
-- **Tools:** Postman, Git, Github

## Key features
-- **Authentication:** Role-based access control (User/Admin/Support Staff).
-- **Complaint Logging:** Users can log issues with detailed  descriptions and categories.
-- **Real-time Status tracking:** Track complaint progress from 'Pending' to 'Resolved'.
-- **Admin Dashboard:** Manage users, assign support staff, and monitor system-wide activity.
